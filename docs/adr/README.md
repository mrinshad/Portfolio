# Architecture Decision Records (ADRs)

This directory contains records of key architectural decisions made in the project.

## Format
Each ADR is named with an incremental 4-digit number: `000X-short-description.md`.
Structure: Title, Status (Proposed/Accepted/Superseded), Context, Decision, Consequences.
